# FIN//AI — Finance × Artificial Intelligence

A futuristic finance landing page built from the IIT Bombay Techfest cyborg-theme brief, reimagined as an AI-finance product.

## Concept

FIN//AI is a fictional financial intelligence platform. It presents AI as a command layer over financial data:

- AI Market Scan
- Risk Engine
- Financial News Sentiment
- Live Market Analytics
- Security & Explainable Intelligence

## Design

- Dark cyber-finance visual system
- Emerald / mint neon accent
- HUD overlays
- AI neural orb
- Animated market chart
- Financial dashboard
- Terminal-style security panel
- Responsive navigation
- Mobile responsive layout
- Custom cursor
- Loading screen
- Scroll reveal effects

## Run

Open `index.html` directly or use VS Code Live Server.

## GitHub / deployment

1. Create a repository named `finai-cyborg`.
2. Upload all files.
3. Enable GitHub Pages.
4. Test the published URL on desktop and mobile.

## Demo recording

Recommended 60–90 seconds:
1. Show the FIN//AI loading screen.
2. Explain the hero: AI + Finance.
3. Show AI Market Scan, Risk Engine and Sentiment Engine.
4. Scroll to the command center.
5. Show live-style analytics UI.
6. Show the security terminal.
7. Finish with the Open Financial Core CTA.

## Important

The market values shown in the design are demonstration UI values, not live financial advice or live market data.
